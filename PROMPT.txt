压力容器设计里，厚壁圆筒的应力分布是最基础也最容易算错的一环，我们想把这块计算独立成一个能被强度校核流程反复调用的后端。它要做的事很纯粹：给定筒体的内半径、外半径、内壁承受的压力、外壁承受的压力，以及筒体两端的轴向约束方式（闭口、开口、还是处于平面应变状态），算出沿壁厚任意半径处的径向应力和环向应力，并单独报出内壁与外壁的环向应力。这不是压力容器的台账系统，也不做定期检验记录，更不是接触力学里的球面压痕计算，就只解一根厚壁筒的弹性应力场。

弹性解按 Lamé 的经典形式给出：径向应力写成 σr = A − B/r²，环向应力写成 σθ = A + B/r²，其中系数 A、B 完全由内外壁的压力边界条件确定。请把这两个系数的推导在实现里解释清楚一次，特别注意 B 项在径向与环向两个分量上的符号是相反的，一处取负一处取正，两边不能都写成同号，否则整个应力场就翻了。轴向条件只影响是否需要额外报出轴向应力与是否计入泊松效应：闭口筒因端盖承压会产生轴向应力，开口筒轴向自由，平面应变则约束轴向应变为零，这三种情形要分别处理，不能用一套公式蒙混。

这根筒的物理正确性可以用几条互相独立的判据卡死，服务的输出必须同时满足它们。第一，弹性力学的径向平衡方程 dσr/dr = (σθ − σr)/r 要在筒壁内处处成立，可用数值差分抽查若干半径点来核对。第二，当壁厚相对半径很小、也就是筒体趋近薄壁时，环向应力应当收敛到薄壁公式给出的量级（内压乘以平均半径再除以壁厚），厚比接近 1.1 时两者应该很接近，而厚比拉到 2 这种明显的厚壁时，内壁环向应力必须显著高于薄壁公式的估计——服务不许全程套用薄壁近似却对外声称给的是 Lamé 精确解。第三，只有内压作用、外压为零时，外壁的径向应力必须恰好等于零。这几条要落到自动化测试里逐条守，而不是靠跑一遍肉眼看。

各计算量之间还有几处可预期的联动关系，也要如实体现：把内压单独放大到两倍、其余不动，整个应力场按比例放大到两倍；在内压之外再叠加一个与内压相等的外压，筒壁受力趋近于均匀静水压状态，偏应力（环向与径向之差）随之下降；把内外半径连同壁厚一起按同一个系数缩放，以无量纲半径 r/a 为横坐标看，应力分布完全不变。请把这些性质当作回归测试的锚点。

输入的合法性要在动手算之前就把住。外半径不大于内半径、内外半径出现非正值、压力符号未按约定给全、平面应变条件下泊松比取到不物理的数值，这些都要在计算入口处挡回并返回带明确原因的结构化错误，绝不能带着坏数据往下算出一个看似正常其实无意义的结果。

对外的能力经 HTTP 暴露：一个接口接收单根筒的完整参数，返回内外壁环向应力、指定半径处的 σr 与 σθ、以及是否超过给定屈服强度（可选按 von Mises 等效应力判断）；一个接口沿壁厚方向按等间距采样，返回 σr(r) 与 σθ(r) 的点列，供上游画应力沿壁分布曲线，这条曲线必须真来自 Lamé 解逐点计算，不许写死成某种衰减形状。服务不需要持久化任何东西，每次请求都是一次独立的纯计算，请确保多个校核请求同时打进来时彼此的中间量互不干扰。为方便使用者上手，随服务附一个只有内压作用的示范算例，参数选得能让人手工核对内壁环向应力确为全场最大拉应力。

实现语言用 Python 3.11，Web 层用 FastAPI，把边界条件求解、Lamé 应力场计算、薄壁极限对照、输入校验分别放进各自的模块，别让主逻辑堆成一个大文件。交付时用容器封装整套服务，能够一步构建镜像并把服务跑起来对外提供上述接口，同时附带一组把前面所有物理判据和联动关系都覆盖到的自动化测试。运行时锁定为 Python 3.11。
